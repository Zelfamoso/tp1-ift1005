# tp1-ift1005

Éléments obligatoires sur les 5 pages
- [ ] Un header contenant un titre h1.
- [ ] Une image servant de logo dans le header.
- [ ] Un menu de navigation qui permet d'accéder aux 5 pages.
- [ ] Un lien du menu visuellement distinct pour la page actuellement affichée.
- [ ] Un main contenant du contenu propre à la page.
- [ ] Quelques paragraphes originaux et des images pertinentes dans le main.
- [ ] Aucun texte Lorem Ipsum : tout le texte doit être rédigé par l'équipe et lié au sujet.
- [ ] Un footer contenant les noms et prénoms des deux membres en gras.
- [ ] Les noms et prénoms sont les seuls mots en gras dans le footer.
- [ ] La date de la dernière mise à jour du site figure dans le footer.

Page d'accueil — index.html
- [ ] Présenter brièvement le site et sa raison d'être.
- [ ] Expliquer ce que les visiteurs peuvent trouver sur le site.
- [ ] Expliquer comment naviguer entre les différentes pages.
- [ ] Ajouter un ou plusieurs paragraphes pertinents.
- [ ] Ajouter au moins une image en lien avec le texte.
- [ ] Vérifier que la page sert réellement de guide à la navigation.

Page À propos — apropos.html
- [X] Décrire clairement le public cible du site.
- [X] Présenter les principes de conception Web vus en cours que le site respecte.
- [ ] Fournir une preuve pour chaque principe présenté : capture d'écran, mesure, extrait de code ou justification concrète.
- [ ] Vérifier que chaque affirmation est accompagnée d'une preuve.
- [X] Ajouter une liste non numérotée des sources Web de toutes les images utilisées sur le site.
- [X] Fournir les sources précises des images, et non simplement Google Images.

Trois pages de contenu original
- [X] Créer 3 pages supplémentaires avec du contenu substantiel et pertinent.
- [ ] Développer suffisamment chaque page pour éviter l'impression d'une page vide ou incomplète.
- [X] Ajouter au moins 3 images dans au moins une des trois pages (le logo du header ne compte pas).
- [X] Faire en sorte qu'au moins une de ces images ait une forme circulaire grâce à une bordure entièrement arrondie.
- [X] Ajouter une liste numérotée contenant une liste imbriquée.
- [X] Numéroter aussi la liste imbriquée, mais avec un type d'indices différent de celui de la liste principale.
- [ ] Créer un petit logo ou badge uniquement avec du CSS, sans utiliser d'image.
- [ ] Donner au badge un aspect soigné, coloré et en relief, avec les effets visuels vus en cours.
- [ ] Intégrer directement dans le HTML une figure SVG personnalisée et originale.
- [ ] Créer une figure SVG représentant un objet reconnaissable ou une scène simple à partir de formes SVG de base.
- [ ] Ne pas reproduire un objet présenté en cours ou dans une démonstration.

Titres, signets et CSS
- [ ] Utiliser au moins 2 titres h2 dans le site, pas nécessairement sur la même page.
- [ ] Donner aux h2 une police, une taille et une couleur qui les distinguent clairement du texte courant.
- [ ] Ajouter un signet en haut et un signet en bas de la page la plus longue.
- [ ] Créer les deux signets avec la balise <a>.
- [ ] Faire pointer le signet du haut vers le bas de la page, et celui du bas vers le haut.
- [ ] Placer les signets de manière clairement identifiable.
- [ ] Mettre toutes les règles CSS dans un seul fichier externe.
- [ ] Utiliser le CSS de manière stratégique et cohérente sur les 5 pages.
- [ ] Utiliser les notions HTML, CSS, éléments graphiques, design Web et SVG vues dans les 5 premières lectures.

Qualité du code et validation
- [ ] Utiliser la structure HTML de base correcte : html, head, body, etc.
- [ ] Utiliser les balises sémantiques appropriées : header, nav, main, footer, h1, p, etc.
- [ ] Indenter et espacer correctement le HTML et le CSS.
- [ ] Vérifier la clarté et la propreté du code.
- [ ] Corriger les fautes d'orthographe et de français.
- [ ] Valider chaque fichier HTML avec le validateur officiel.
- [ ] Valider le fichier CSS avec le validateur officiel.
- [ ] Corriger les erreurs de validation et vérifier les avertissements pertinents.

Vérifications finales et remise
- [ ] Tester les liens de navigation entre les 5 pages.
- [ ] Vérifier que le menu met en évidence la bonne page sur chacune des 5 pages.
- [ ] Vérifier que toutes les images s'affichent correctement.
- [ ] Tester les deux signets de la page la plus longue.
- [ ] Vérifier l'affichage du SVG et du badge CSS.
